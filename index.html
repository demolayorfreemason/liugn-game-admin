⚠ Read this first — how this admin works

Admin changes apply to the next upload, not to copies already uploaded.

This admin does not live-connect to a game file that’s already on itch or any other site. A game uploaded as a plain HTML file stands alone — there’s no server behind it — so nothing changed here can reach into that uploaded copy and change it after the fact.

  1. Make your changes here — pick Full or Clean, add your beats, take songs out, set up the store.
  2. Download the version file below. That file is what the next build of the game is made from.
  3. Build the new game file from that version file, then upload it to replace the old one. Only then do players get the change.

For changes inside a copy people already have, the controls have to live in the game itself — and they do: the game’s own menu has music on/off, music and people volume, and the playlist. This admin decides what ships in the next upload; the in-game controls handle the copy in a player’s hands.
